## `$ featured_projects`

### 01 — Power Consumption ETL Pipeline

**End-to-end batch data engineering pipeline**

Built a batch ETL system to process household electricity consumption data and transform raw records into analytical datasets.

**Technologies:** Python · Apache Airflow · Apache Spark · HDFS · Snowflake · Docker · Power BI

**Key components:**
- Data ingestion and Parquet storage.
- Bronze / Silver / Gold data layers.
- Data cleaning and transformation with Spark.
- Analytical fact and time dimension tables.
- Power BI dashboards for consumption analysis.

[View Repository](https://github.com/yousef-140/power-consumption-etl)

---

### 02 — Egypt Real Estate Intelligence

**Real estate data collection and price prediction**

Developed a data platform for collecting and analyzing real estate listings across Greater Cairo.

**Technologies:** Python · BeautifulSoup · Airflow · HDFS · Spark MLlib · Random Forest · Streamlit

**Key components:**
- Web scraping and data collection.
- Data processing and feature engineering.
- Real estate price prediction.
- Interactive market analytics dashboard.

[View Repository](https://github.com/yousef-140/egypt-real-estate-intelligence)

---

### 03 — Custom Knowledge RAG Platform

**Document-based question answering system**

Built a Retrieval-Augmented Generation platform that allows users to query their own documents using hybrid retrieval.

**Technologies:** Python · FastAPI · FAISS · BM25 · Ollama · Streamlit · SQLite

**Key components:**
- PDF document processing.
- Hybrid retrieval using vector and keyword search.
- LLM-powered question answering.
- Source citations and API endpoints.
- Query caching and retrieval evaluation modules.

[View Repository](https://github.com/yousef-140/custom-knowledge-rag-platform)

---

### 04 — Research Coach

**Multi-agent AI research assistant**

Developed an AI research assistant designed to discover, organize, and evaluate research sources.

**Technologies:** Python · FastAPI · FAISS · SQLite · LiteLLM · APScheduler

**Key components:**
- Multi-agent workflow: Scout, Curator, Critic, and Coach.
- Research discovery and source collection.
- Source credibility scoring.
- Arabic and English support.
- Scheduled research digests.

[View Repository](https://github.com/yousef-140/research-coach-)
